# MP3转文本工具 - 修改说明

## 项目概述

本项目实现了音频文件（MP3/WAV等）转文本的功能，参考了 `texttomp3.py` 的GUI设计风格，使用Whisper模型进行语音识别。

## 主要功能

1. **文件选择**：支持选择MP3、WAV、M4A、FLAC、OGG等音频格式
2. **模型选择**：提供5种不同大小的Whisper模型（tiny/base/small/medium/large）
3. **语音转文本**：使用Whisper模型将音频转换为简体中文文本
4. **GPU加速**：自动检测并使用NVIDIA CUDA GPU加速，大幅提升转换速度
5. **自动保存**：转换完成后自动保存为TXT文件到原文件目录

## 技术实现

### 核心库
- **openai-whisper**：OpenAI开源的语音识别模型，支持多语言包括中文
- **torch**：PyTorch深度学习框架，支持CUDA GPU加速
- **tkinter**：Python标准GUI库，用于构建图形界面
- **threading**：多线程处理，避免UI冻结

### 主要模块

1. **check_cuda_available()**：检测CUDA GPU是否可用
2. **get_device()**：自动选择最佳计算设备（优先GPU）
3. **load_whisper_model()**：加载Whisper模型到指定设备，支持模型缓存复用
4. **select_file()**：文件选择对话框，显示文件大小
5. **convert_mp3_to_text()**：核心转换函数，在后台线程中执行，输出简体中文
6. **GUI界面**：参考原项目的布局风格，包含进度条、GPU状态提示

## 使用说明

1. 安装依赖：
   - CPU版本：`pip install -r requirements.txt`
   - GPU版本（推荐）：访问 https://pytorch.org/get-started/locally/ 根据CUDA版本安装对应torch
2. 运行程序：`python mp3totext.py`
3. 程序会自动检测GPU，界面会显示当前使用的设备（GPU/CPU）
4. 选择音频文件并点击转换
5. 转换结果会自动保存为简体中文TXT文件

## 注意事项

- **GPU加速**：如果检测到NVIDIA CUDA GPU，会自动使用GPU加速，速度可提升10-50倍
- **简体中文输出**：程序默认输出简体中文，通过language="zh"和initial_prompt确保输出质量
- 首次使用需要下载模型文件，请确保网络连接
- 模型文件较大，建议使用base或small模型平衡速度和精度
- 转换过程在后台线程执行，不会阻塞UI界面
- GPU版本需要安装CUDA版本的PyTorch，详见requirements.txt注释
